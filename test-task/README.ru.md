# Тестовое задание и курс: BrownEvents

> [Карта репозитория](../ru/README.md) · [Правила сдачи](rules.ru.md) · English version — soon

**Главное.** BrownEvents — работающее приложение для конференций, которое два года никто не поддерживал. Вы разбираетесь в нём и чините его вместе с консольным AI-агентом. Есть два способа пройти этот проект: коротко, чтобы идти на интервью, или долго, чтобы научиться.

## Выберите режим

| | Тестовое к интервью | Курс |
|---|---|---|
| **Для кого** | стек уверенный, хочется на интервью | есть время, хочется разобраться; позиции в вашей стране пока нет |
| **Что внутри** | три составных задания | ядро из пяти заданий + модули на выбор |
| **Сколько** | около 2 дней при уверенном стеке | ядро — 1–2 недели, модули — сколько захотите |
| **Итог** | созвон по тестовому | созвон по тестовому после ядра и блока T1–T3; модули — для себя и для проекта |
| **Начать** | [Тестовое: T1–T3](exam/README.md) | [Курс: ядро и модули](course.ru.md) |

Материал у режимов общий. Задания тестового собраны из заданий курса, только упакованы плотнее. Поэтому в курсе T1–T3 идут отдельным блоком сразу после ядра: перед созвоном их стоит сделать в любом режиме.

Дедлайна нет. Если приходится учить стек по ходу, работа займёт больше времени, и это нормально.

## С чем вы работаете

Стек: **ASP.NET Core 6 + EF Core 6 + React + Vite + PostgreSQL**. Команда `docker-compose up --build` поднимает всё приложение. Сделайте это до первого задания.

Код лежит в отдельном репозитории-шаблоне **[brown-events-pilot](https://github.com/dzmitry-varabei/brown-events-pilot)**. Нажмите **Use this template** и создайте свою копию. Если копия приватная, добавьте проверяющего коллаборатором. Вся работа идёт в ней: issues, ветки, PR, devlog, отчёт.

Основные сущности: конференция, сессия, спикер, зал, участник, регистрация.

## Как устроено каждое задание

Все задания написаны по одному шаблону:

- **Зачем** — что вы будете уметь после задания.
- **Тикет** — текст задачи по-английски, как на проекте.
- **Докажи, что работает** — что приложить к PR, чтобы результат был виден без веры на слово.
- **Объясни** — 2–4 вопроса. Отвечаете своими словами в devlog, на созвоне спросят о том же.
- **Цена** — сколько стоила задача.

Приложение устроено так, как бывает в жизни: в коде есть заложенные проблемы, и найти их — часть работы.

## Нужно для работы

- **Консольный AI-агент**: Claude Code, Codex CLI, Gemini CLI, Copilot CLI или Pi. Cursor, веб-чаты и плагины IDE не подходят: их сессии не попадут в отчёт.
- **Docker** и **Node.js 20+**.
- Правила сдачи — ветки, PR, devlog, отчёт — [на отдельной странице](rules.ru.md). Прочитайте её до первого задания.
