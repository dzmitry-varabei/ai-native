# Хуки: правило как код

> База · до этого: [контекст](context.md) · [Карта](../README.md)

**Главное.** Хук — скрипт, который harness запускает сам на определённом событии: перед вызовом инструмента, после правки файла, в конце ответа. Правило в CLAUDE.md — просьба, которую модель может забыть. Хук — код, который harness запускает при каждом совпадении события и фильтра. Что будет при ошибке или тайм-ауте самого хука, нужно проверить.

## Зачем их придумали

Ни люди, ни модели не соблюдают письменные напоминания стабильно. «Не коммить без тестов» в CLAUDE.md работает, пока модель про это помнит, а в длинной сессии правило тонет среди сотен строк контекста. Хук выполняет не модель, а harness, поэтому забыть его нельзя.

Принцип: если нарушение правила дорого, сделайте его невозможным, а не просите агента «не забыть».

## Как это устроено в Claude Code

- **Событие.** Например, `PreToolUse` — перед вызовом инструмента, `PostToolUse` — после успешного вызова, `Stop` — когда агент закончил отвечать, `SessionStart` — при старте сессии. Полный список — в [документации](https://code.claude.com/docs/en/hooks).
- **Фильтр (matcher).** На какие инструменты реагировать: `Bash`, `Edit|Write`, `Read`.
- **Команда.** Скрипт получает на вход JSON с деталями вызова: какой инструмент, какой файл, какая команда.
- **Решение.** Код выхода 2 в `PreToolUse` блокирует вызов, а текст ошибки (stderr) видит модель и может поправиться. В `PostToolUse` код 2 — способ показать агенту проблему: при коде 0 обычный вывод хука модели не показывается. Но хук может вернуть структурированный контекст — поле `additionalContext` в JSON-ответе.

Хуки описывают в `.claude/settings.json` в репозитории — тогда они общие для команды — или в личных настройках.

## Два примера

- **Запретить чтение `.env`.** Основной способ — запрет в настройках разрешений. Хук — страховка поверх: `PreToolUse` на `Read`, если в имени файла есть `.env`, выйти с кодом 2. Команды вроде `cat .env` идут через `Bash`, их тоже надо закрыть.
- **Автозапуск тестов.** `PostToolUse` на `Edit|Write`: прогнать линтер и тесты затронутого модуля, при падении выйти с кодом 2 — тогда агент увидит ошибку. Он узнаёт о поломке сразу, а не на ревью.

<details>
<summary>Подробнее: как выглядит первый пример и ещё одна идея</summary>

В `.claude/settings.json`:

```json
{ "hooks": { "PreToolUse": [ { "matcher": "Read",
  "hooks": [ { "type": "command", "command": "\"$CLAUDE_PROJECT_DIR\"/.claude/hooks/no-env.sh" } ] } ] } }
```

Скрипт `.claude/hooks/no-env.sh`:

```bash
#!/bin/bash
path=$(jq -r '.tool_input.file_path')
if [[ "$path" == *.env* ]]; then echo "Чтение .env запрещено" >&2; exit 2; fi
exit 0
```

Скрипту нужны права на запуск: `chmod +x .claude/hooks/no-env.sh`. Маска `*.env*` ловит и `.env.local`. Код выхода 1 вызов не блокирует — только 2. Это частая ошибка.

Ещё идея: **стоп на огромный дифф.** `PreToolUse` на `Bash` с `git commit`: посчитать размер изменений и остановить коммит, если он больше порога. Огромный дифф почти всегда значит, что агент ушёл не туда, а человек такой PR не прочитает.

</details>

## Что вешать на хук, а что нет

- **На хук** — правила, нарушение которых нельзя пропустить: секреты, тесты перед коммитом, запрет опасных команд, форматирование.
- **В CLAUDE.md** — то, что требует суждения: стиль решений, архитектурные договорённости, «как у нас принято».
- **Не перегружайте.** Медленный хук на каждую правку тормозит работу и тратит время на каждом шаге.

То же правило работает и вне агента: git pre-commit хук, проверки в CI. Хуки агента — ещё один слой той же идеи.

Подробно — лонгрид [«Из чего сделан агент»](../longread/02-fundamentals.md), раздел про hook.

## Проверь себя

- В CLAUDE.md написано «не трогай папку `migrations/`», но агент дважды её правил. Что вы сделаете?
- Вы написали хук, который должен блокировать коммит без тестов, но коммит всё равно проходит. Что проверите первым?
- Команда хочет хук, который перед каждой правкой гоняет весь набор тестов на десять минут. Чем это плохо и что предложите взамен?
- Хук на `Read` запрещает читать `.env`, но агент всё равно показал секрет в чате. Каким путём он мог его получить?
