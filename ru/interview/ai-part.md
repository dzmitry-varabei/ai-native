## Проверь себя

- Вас просят перечислить, что уходит в API вместе с «привет». Сможете ответить по тому, что видели сами, а не по догадке?
- Интервьюер просит объяснить MCP на примере. Какой сервер вы подключали сами и что агент с ним сделал?
- Вас просят сравнить ChatGPT и Claude Code на задаче «починить упавший тест». Что каждый из них сможет сделать сам?
- Интервьюер просит показать хук, который вы сами написали. Что покажете?
